# 迷雾牌局 | Mist Card Game

一款受非对称推理与哥特式悬疑氛围启发的原创单机卡牌策略游戏原型。

> 非官方同人灵感项目，与《第五人格》及其版权方无隶属关系。角色、规则、界面与素材均为原创原型内容。

## 当前版本：V0.7.2.1

### 已实现
- 无需安装依赖，浏览器直接运行
- 选择求生者角色，与 AI 猎手进行单人对局
- 回合制行动：攻击、治疗、侦查、蓄势
- 手牌与能量系统：开局抽取 3 张卡牌，此后每回合结束时随机抽取 1 张；部分卡牌仍可触发额外抽牌
- 生命值、恐惧值与胜负判定
- 基础 AI 行动逻辑
- 五台密码机与独立破译进度条
- 消耗能量进行破译，全部完成后为两扇逃生大门通电
- 东、西两侧大门独立破译进度，任意一扇开启即可逃脱
- 监管者在大门阶段提高压迫，并有概率干扰破译进度
- 成功开启大门后可主动选择逃离庄园
- 先知、医生、慈善家拥有各自的主动技能，每回合可使用一次
- 开局可选择简单、普通、困难三档监管者难度，分别调整监管者生命、攻击压力与大门干扰强度
- 扩展卡牌池：快速校准、大门工具箱、烟幕掩护，分别支持密码机推进、大门推进与防御削弱组合
- 先知使用「预兆」获得 3 点护盾，医生使用「疗愈」恢复 5 点生命，慈善家使用「灵巧」获得 1 点能量（能量上限为 5）
- 监管者专精由 AI 在每局开始时随机决定，玩家无法手动选择；监管者会根据求生者手牌、能量、生命值、密码机与大门进度判断是否使用技能
- 监管者保留「控制」基础技能，并随机携带「坚壁」或「追猎」专精：控制会束缚求生者下一回合的出牌与破译行动；坚壁使监管者接下来 2 个求生者行动回合受到的伤害降低 30%；追猎使本次攻击额外造成 3 点伤害；专精技能冷却 4 回合
- 卡牌池扩展至 18 种独特卡牌，加入迷雾束缚、坚韧意志、破绽洞察、以守为攻、超频思维、稳住阵脚与破译脉冲，覆盖控制、防御、增伤、反击、资源与破译
- 哥特式庄园视觉主题与响应式布局

### 运行方式
下载或克隆仓库后，直接用现代浏览器打开 `index.html` 即可。
