# 迷雾牌局 | Mist Card Game

一款受非对称推理与哥特式悬疑氛围启发的原创单机卡牌策略游戏原型。

> 非官方同人灵感项目，与《第五人格》及其版权方无隶属关系。角色、规则、界面与素材均为原创原型内容。

## 当前版本：V0.2.0

### 已实现
- 无需安装依赖，浏览器直接运行
- 选择求生者角色，与 AI 猎手进行单人对局
- 回合制行动：攻击、治疗、侦查、蓄势
- 手牌与能量系统
- 生命值、恐惧值与胜负判定
- 基础 AI 行动逻辑
- 五台密码机与独立破译进度条
- 消耗能量进行破译，全部完成后触发阶段胜利
- 哥特式庄园视觉主题与响应式布局

### 运行方式
下载或克隆仓库后，直接用现代浏览器打开 `index.html` 即可。
